## Overview

**KHADIJAH-TUL-QUBRAH by Meer&Mus** is a full-stack luxury fashion commerce, custom commission, and atelier management engine designed for high-end bridal couture, ready-to-wear, and bespoke artisan tailoring.

## Key Features

- **Storefront & Catalog**: Showcases handcrafted bridal lehengas, peshwas, raw silks, and party wear.
- **Custom Dress Builder ("Create Your Own")**: Interactive 6-step bespoke commission studio for style, fabric, hand embroidery, color, and precision measurements.
- **Live Order & Timeline Tracking**: Real-time customer tracking from order receipt, designer review, workshop embroidery, and quality check to courier dispatch.
- **Role-Based Portals**:
  - **Owner & Admin Launchpad**: Real-time sales analytics, video deals & discount campaigns, and product launches.
  - **Designer Studio**: Custom quotation generation, versioning, and tailoring pattern calibration.
  - **Production & Workshop**: Multi-stage floor tracking (Cutting, Embroidery, Assembly, Finishing, Quality Check).
  - **Customer Relations / Agent CRM**: VIP inquiries and measurement management.
- **Location**: Sole official boutique and workshop in **Jampur, District Rajanpur, Punjab, Pakistan**, serving local walk-ins, nationwide courier, and worldwide international delivery.

## Tech Stack

- **Frontend**: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS, Lucide Icons
- **Backend**: NestJS, TypeScript, PostgreSQL / Prisma ORM, Redis, Jest, Supertest
- **Mobile**: React Native / Expo Architecture

## Getting Started

### Backend
```bash
cd backend
npm install
npm run start:dev
# Server runs on http://localhost:4000
```

### Frontend
```bash
cd frontend-admin
npm install
npm run dev -p 3001
# Frontend runs on http://localhost:3001
```
